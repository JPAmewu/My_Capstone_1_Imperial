# Resources

This folder is reserved for references, reading lists, external links, and
supporting materials used across the project.

No external resource files are currently committed. Project-generated evidence
belongs with the relevant weekly record, while project-wide technical material
belongs in [Documentation](../Documentation/).

Future additions should identify the author or organisation, title, publication
date, stable URL or citation, access date where appropriate, and how the source
informed the project. Copies of weekly notebooks, query files, or datasets
should not be placed here.
