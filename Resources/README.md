# Resources

This folder is reserved for references, reading lists, external links, and
supporting materials used across the project.

Project-generated evidence belongs with the relevant weekly record, while
project-wide technical material belongs in [Documentation](../Documentation/).

## Book bookmarks

### Machine learning and deep learning

1. **Hands-On Machine Learning with Scikit-Learn and PyTorch: Concepts, Tools, and Techniques to Build Intelligent Systems**
   - Author: Aurélien Géron
   - Publisher: O'Reilly
   - Focus: Practical machine learning and deep learning with Scikit-Learn and PyTorch.

2. **Machine Learning for Business Analytics: Concepts, Techniques, and Applications in Python**
   - Authors: Galit Shmueli, Peter C. Bruce, Peter Gedeck, and Nitin R. Patel
   - Edition: Second edition
   - Publisher: Wiley
   - Focus: Applying machine-learning techniques to business analytics using Python.

3. **An Introduction to Statistical Learning with Applications in Python**
   - Authors: Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor
   - Series: Springer Texts in Statistics
   - Publisher: Springer
   - Focus: Statistical-learning foundations and their implementation in Python.

### Large language models

4. **50 ML Projects to Understand LLMs: Investigate Transformer Mechanisms Through Data Analysis, Visualization, and Experimentation**
   - Author: Mike X Cohen
   - Focus: Project-based exploration of transformers and large language models.

## Contribution guidance

Future additions should identify the author or organisation, title, publication
date, stable URL or citation, access date where appropriate, and how the source
informed the project. Copies of weekly notebooks, query files, or datasets
should not be placed here.
