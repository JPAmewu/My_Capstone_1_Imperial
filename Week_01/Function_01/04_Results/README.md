# Week 01 Function 01 results

- `observations.csv` is a readable table containing `x1`, `x2`, objective
  output, query number, and running best.
- `summary.json` records the validated observation count, dimensionality, best
  query, best input, best output, latest output, and strategy.

Both files are generated deterministically by
[`../02_Code/analyse_function_01.py`](../02_Code/analyse_function_01.py).
