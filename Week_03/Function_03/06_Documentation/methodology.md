# Methodology

## Evidence boundary

Weeks 1-2 observed; Week 3 proposed only. The analysis reconstructs 17 observations from immutable starter arrays and the canonical ledger. The Week 3 query is held separately as a proposal. No outcome is imputed.

## Function-specific acquisition

Function 03 uses **GP-UCB**, as documented in `Week_03/02_Notebook/Week_3_Capstone.ipynb`. Decision record: Chosen using evidence through Week 2, before the Week 3 return.

This policy is adaptive and heuristic. It was selected using evidence available through Week 2; it is not a randomized or statistically controlled acquisition comparison. For Week 13, the reason was recorded before Week 13 outcomes existed.

## Validation

Inputs are finite and bounded; the proposal is distinct, capped at `0.999999`, and formatted as `0.670026-0.057881-0.658241` with six decimals per coordinate. Results are descriptive within Function 03 and imply neither causality nor global optimality.
