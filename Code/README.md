# Reusable code

This folder is reserved for reusable Python modules, command-line tools, and
tested helper functions shared by more than one weekly analysis.

The canonical implementations currently remain inside the notebooks under
[`Week_01`](../Week_01/) through [`Week_13`](../Week_13/). No notebook code has
yet been promoted into a standalone module, so this folder intentionally
contains no Python files.

Code should be added here only when it has a stable interface, is useful across
multiple weeks, and can be validated independently of notebook cell order.
