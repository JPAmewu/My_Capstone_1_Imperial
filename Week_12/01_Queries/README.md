# Week 12 queries

This folder contains the eight reproducible proposals generated by the
corruption-aware Week 11 GP-UCB workflow for submission in Week 12:

- [`week_12_query_points.txt`](week_12_query_points.txt)

The generating code and duplicate checks are in the
[Week 11 notebook](../../Week_11/02_Notebook/Week_11_Capstone.ipynb). These are
proposal coordinates only: no verified Week 12 returned outputs are preserved,
so the file must not be treated as a completed query/output dataset.

The notebook under `02_Notebook` is a historical Week 10-derived placeholder
and is not evidence of a separate Week 12 optimisation run.
