# Project documentation

This folder contains project-wide documentation that applies across the weekly
Bayesian optimisation experiments.

- [Dataset datasheet](DATASET_DATASHEET.md) documents the origin, structure,
  provenance, limitations, and intended use of the observation data.
- [Model card](MODEL_CARD.md) documents the Gaussian Process modelling approach,
  acquisition strategies, evaluation constraints, and known limitations.
- The [project README](../README.md) provides the repository guide and canonical
  notebook index.

Week-specific methods, results, and evidence gaps remain with their source
notebooks under [`Week_01`](../Week_01/) through [`Week_13`](../Week_13/).
